# 5-minute KLS Demo

1. Start with BAT1, SW1, R1 = 470 Ω, LED1, M1, GND. Default switch is closed.
2. Click **SIMULATE**. Show LED ≈ 14.7 mA and motor ≈ 300 mA.
3. Open SW1. Show LED and motor current drop to ≈ 0.
4. Change R1 to 100 Ω. Show LED over-current warning.
5. Switch to Junction mode. Click a wire to split it or click a real component terminal to anchor a branch.
6. Click a wire. Drag an edit dot and move a component. Show the topology remains connected.
7. Stop and restart simulation. Explain that React owns the UX while Python owns the electrical calculation.
