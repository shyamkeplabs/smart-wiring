# Resume-ready wording

### Full-stack project bullet
Built a graph-based circuit wiring and bounded DC simulation environment using React/TypeScript, React Flow, Python, and FastAPI; transformed interactive pin/junction connections into backend electrical nets and solved Battery, Switch, Resistor, LED, and Motor circuits with voltage/current/power analysis and fault validation.

### Wiring / frontend bullet
Engineered Tinkercad-style editable wiring interactions with snap-to-pin connections, smart 90°/45° routing, junction-aware topology, movable component-following wires, net highlighting, and interactive wire bend points.

### Backend / testing bullet
Implemented deterministic MNA-based DC analysis with topology checks for missing ground, floating terminals, source shorts, LED over-current, and motor current limits; added API and solver regression tests for valid, open-switch, junction, and fault scenarios.
