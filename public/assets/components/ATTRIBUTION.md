# Component SVG assets

The SVG component artwork in this folder was created specifically for the KLS prototype. It is original artwork and is **not copied from Autodesk Tinkercad**.

The visual direction is intentionally inspired by the approachable, physical-breadboard feel common to beginner electronics tools: soft shadows, metallic/plastic surfaces, readable component proportions, and obvious terminals.

For reference, Fritzing also maintains an open parts repository containing SVG-based component graphics; its repository states that parts are composed of metadata plus SVG graphics, and the Fritzing app repository states that its part designs are under a Creative Commons Attribution-ShareAlike license.
